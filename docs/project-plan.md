# План сторінок «Автопідбір»

Режим React Router: декларативний (`BrowserRouter`, `Routes`, `Route`), пакет `react-router` 7.18.4.

| Адреса | Компонент | Параметри | Джерело запису | Якщо запису немає |
|---|---|---|---|---|
| `/` | `HomePage` | — | — | — |
| `/parts` | `CatalogContainer`, `PartListPage` | `q`, `available` (query) | `src/data/parts.js` | «За цими фільтрами нічого не знайдено» |
| `/parts/:partId` | `PartDetailsPage` | `partId` (шлях) | `src/data/parts.js` | сторінка «Запчастину не знайдено» |
| `/searches` | `SearchesPage` | `q`, `urgent`, `sort` (query) | поточна колекція (`SearchesProvider`) | порожня колекція або порожній результат пошуку |
| `/searches/new` | `SearchCreatePage` | `partId` (query) | `src/data/parts.js` | без параметра — пояснення; з невідомим — «Неможливо підготувати підбір» |
| `/searches/:searchId` | `SearchDetailsPage` | `searchId` (шлях) | поточна колекція | сторінка «Підбір не знайдено» |
| `/searches/:searchId/edit` | `SearchEditPage` | `searchId` (шлях) | поточна колекція | сторінка «Підбір для редагування не знайдено» |
| `*` | `NotFoundPage` | — | — | 404 із посиланнями |

## Дерево маршрутного вмісту

```
AppLayout (PartSelectionProvider, Outlet)
  Головна
  Запчастини
    Каталог
    Деталі запчастини
  SearchesLayout
    Список підборів
    Новий підбір
    Деталі підбору
    Редагування підбору
  Сторінка 404
```

## Приклади адрес для перевірки

- `/parts?q=колодки&available=1`
- `/parts/p-001`
- `/searches/new?partId=p-001`
- `/searches/s-001/edit`
- `/unknown`, `/parts/missing`, `/searches/missing/edit`

## Модель підбору (Л 3.1)

| Поле | Правило |
|---|---|
| `id` | створюється операцією додавання, у формі не редагується |
| `partId` | посилання на наявну запчастину каталогу |
| `carBrand` | обов'язкове, від 2 до 30 символів без крайніх пробілів |
| `carModel` | обов'язкове, до 40 символів |
| `comment` | обов'язковий, від 10 до 500 символів без крайніх пробілів |
| `quantity` | обов'язкове ціле число від 1 до 10 |
| `urgent` | логічне значення |
| Зв'язок полів | для `quantity` > 4 коментар має містити не менше 20 символів |

Підбір є запитом на підбір запчастини, а не підтвердженим замовленням. Збереження підбору не змінює `available` у каталозі.

Параметри списку `/searches`: `q` (пошук у назві запчастини, марці, моделі та коментарі), `urgent` (`all`, `yes`, `no`), `sort` (`part`, `quantity-asc`, `quantity-desc`).

## Рівень даних і збереження (Л 3.2)

| Питання | Рішення |
|---|---|
| Головна сутність | підбір (`id`, `partId`, `carBrand`, `carModel`, `comment`, `quantity`, `urgent`) |
| Основне джерело | mock сервіс із `localStorage` (ключ `autopidbir.searches.v1`), затримка 600 мс, одноразова відмова |
| REST адаптер | `apiSearchService.js` за контрактом `/searches`; перевірено локальною заглушкою, реальний API не підключено |
| Вибір джерела | `REACT_APP_DATA_SOURCE`, `REACT_APP_API_BASE_URL` (`.env.example`) |
| Довідник запчастин | залишається локальним (`src/data/parts.js`) |
| Стани розділу | завантаження, помилка з повтором, успіх, порожня колекція, відсутність збігів |
| Межі | немає автоматичної синхронізації між вкладками, немає автентифікації й міграції локальних записів на сервер |

## Продуктивність (Л 4.1)

Вимірювалось React Profiler (`actualDuration`) для `SearchTable` у режимі розробки (`npm start`, Strict Mode), 300 підборів у `localStorage`, Chromium; дія «закрити повідомлення після видалення» (15 вимірювань) і введення чотирьох символів у пошук (12 вимірювань), три прогони. Це не вимірювання повної затримки від кліку до кадру.

| Дія | Медіана до змін | Медіана після `memo(SearchRow)` + `useCallback` |
|---|---|---|
| Закриття повідомлення | 23–29 мс | 1–10 мс |
| Введення символа в пошук | 22–24 мс | 28–33 мс |

Висновок: для закриття повідомлення непотрібний повторний рендер 300 незмінених рядків усунено; для введення пошуку медіана не покращилась (трохи гірша через порівняння props), зменшились лише поодинокі піки. Для реального обсягу (кілька записів) затримка не помітна й без мемоізації; зміну залишено лише як виміряно виправдану для великої колекції.
